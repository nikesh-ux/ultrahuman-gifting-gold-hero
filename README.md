# Ultrahuman gifting prototype · live build

The current gifting prototype: gold-card hero, gift panels, dark highlights, the scroll-driven app intro with video, occasions and FAQ. Published with GitHub Pages.

- `src.html`: prototype source. Rebuild with `python3 build.py` (writes `artifact.html` and `index.html`).
- `index.html`: the built prototype, open directly in a browser.
- `extras/`: standalone files from the same work.
  - `metal-cards.html`: the three engraved metal cards on white.
  - `hero-cards-animation.html`: first hero animation test.
  - `hero-intro-ideas.html`, `-2.html`, `-3.html`: intro animation ideas 01 to 18 (18 is the one used in the hero).
  - `hero-split-ideas.html`: ten split-layout hero ideas.

Hero in this snapshot: gold headline and mark appear, the gold card rises from below, the headline fades to #F3F3F3, then four cards come out behind it. Detail pages end at "How it works".
